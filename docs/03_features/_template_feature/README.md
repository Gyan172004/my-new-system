# Feature template

**Purpose:** Copy this folder when adding a feature.

**Related Kanban work:** none

## Canonical documents

- `requirements/feature_req.md`
- `specifications/technical/tech_design.md`
- `specifications/engineering/eng_design.md`
- `pseudo_code/logic_and_state.md`

Copy this directory as the starting point for a new feature, rename it using a stable `snake_case` slug, and complete all four documents before substantive implementation. Do not copy existing cross-cutting contracts unless the new feature needs them.
